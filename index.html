Open-source Python library for MotoGP data — inspired by FastF1. Session-centric access to qualifying, sprint and race data from the official PulseLive API and DORNA timing PDFs, with pandas DataFrames, plotting and gap analysis built in.

Apex Telemetry

Sector-by-sector comparison of F1 qualifying laps. Pick a session and two drivers — get sector deltas, speed traps and an interactive track-dominance map rendered on canvas with official turn numbers.

  • React
  • Flask
  • FastF1
  • Canvas

Pune.Rent

Full-stack real-estate mapping app for rental discovery in Pune. Interactive Leaflet map with marker clustering, area & price filters, market stats, and a Flask + PostgreSQL backend with scheduled data refreshes.

  • React
  • Leaflet
  • Flask
  • PostgreSQL

LipReader

Deep-learning lip reading inspired by the LipNet paper. A CNN + RNN architecture with CTC loss reads mouth movements from video frames and predicts the spoken sentence.

  • TensorFlow
  • OpenCV
  • CTC
  • Seq2Seq

Chest Cancer Classification

End-to-end medical imaging pipeline: CNN classification of chest CT scans with MLflow experiment tracking, DVC data versioning and a Dockerized Flask app ready for deployment.

  • CNN
  • MLflow

  • Docker

Football Analysis

Computer-vision match analysis: YOLOv5 detection and tracking of players, referees and the ball; KMeans shirt-colour team assignment; optical flow for camera motion; perspective transform to measure real speed and distance.
